## ✨ Features & Architecture

- **Dark-Mode Luxury Aesthetic**: Deep black palette (`#0B0B0C`), luxury surface cards (`#161618`), and champagne/gold accents (`#E5C396`).
- **Interactive Sticky Navigation**: Active section tracking pill menu, glowing availability status, and a smooth mobile slide-out drawer.
- **Hero Section**: Display typography with elegant serif italic accents, rotating monogram badge, and ambient radial golden lighting.
- **Selected Work & Domain Filtering**: Interactive 11-project engineering catalog filterable by domain (*All*, *Backend & Systems*, *Security & Edge*, *Apps & Tooling*) with architecture modal popups, engineering highlights, and live repository/release links.
- **Services ("What I Do")**: 4 feature cards covering Backend & Systems Engineering, Full-Stack & Graphics Engineering, AppSec & Network Security, and Edge & Offline-First Runtimes.
- **About & Dual Certifications**: Highlights Cisco CCNA 1-3 & CSS NC II dual certifications and animated skill progress meters.
- **Client Testimonials**: Feedback carousel featuring client reviews and local image assets.
- **High-Conversion Footer & Contact Modal**: Quick contact modal with one-click email and phone copy support, multi-column navigation, and newsletter subscription form.

## 💻 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
1. Clone the repository:
```bash
git clone https://github.com/ben-bacs/Portfolio.git
cd Portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```
